Privacy Policy

Last updated: September 26, 2026

Studio Upload ("the application") is a private tool operated by the owner of the YouTube channels it uploads to. This policy explains what data the application accesses and how it is handled.

1. Data accessed

With your explicit consent through Google's OAuth screen, the application requests the scopes youtube.upload and youtube.readonly. It uses them only to:

  • upload videos produced by the operator to the authorized channel, with their title, description, tags and thumbnail;
  • read the name and identifier of the authorized channel to confirm the right channel is used.

The application does not read, collect or store any other data: no viewing history, subscribers, comments, contacts, emails or personal information.

2. Storage

The only data stored is the OAuth refresh token, kept in a local file on the operator's computer. It is never sent to any server other than Google's, never shared and never sold.

3. Sharing

No data is shared with third parties. Uploaded videos are sent directly to YouTube.

4. Google and YouTube

The application uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and your data is handled under the Google Privacy Policy. Studio Upload's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access

You can revoke the application's access at any time at myaccount.google.com/permissions. Revoking it makes the stored token useless; the operator can delete it on request.

6. Contact

For any question or deletion request: hoodcycle.contact@gmail.com.
